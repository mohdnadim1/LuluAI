# Contributing to LuluAI

We welcome contributions from the community! Whether you're fixing a bug, adding a feature, or improving documentation, your help is appreciated.

## How to Contribute

1.  **Fork the repository** and create your branch from `main`.
2.  **Set up your development environment** by installing the dependencies in `requirements.txt`.
3.  **Make your changes** and ensure that the code follows the project's style guidelines.
4.  **Add tests** for any new features or bug fixes.
5.  **Run the existing tests** to ensure that your changes don't break anything.
6.  **Update the documentation** if you've added or changed any features.
7.  **Submit a pull request** with a clear description of your changes.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

## Reporting Bugs

If you find a bug, please open an issue on GitHub and provide as much detail as possible, including:

-   A clear description of the bug.
-   Steps to reproduce the bug.
-   The expected behavior.
-   The actual behavior.
-   Your system information (OS, Python version, etc.).

Thank you for contributing to LuluAI!
